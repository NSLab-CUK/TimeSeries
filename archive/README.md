# Archived source and documentation

`paper_analysis/` contains unchanged scripts from the original release. They retain historical relative paths and require the internal posttraining analysis artifacts. They are preserved for provenance, not adapted as executable entry points for this repository layout. Use `reproduce.py plot` for supported plot generation.

`ORIGINAL_RELEASE_README.md` and `original_release_manifest.csv` describe the earlier staging tree. Current paths and commands are in the repository root README and `docs/`.
